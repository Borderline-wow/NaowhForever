# Bundled English callouts

Generated for Smart Reminders with Windows System.Speech (Microsoft Zira Desktop),
rate 1, volume 100. These are synthesized stock-voice clips, not recordings of
Naowh or another person. No media was copied from another addon.

- dispel-me.ogg: "Dispel me."
- move-out.ogg: "Move out."
- use-a-defensive.ogg: "Use a defensive."
- stoneform-ready.ogg: "Stoneform." Dedicated to cooldown-gated aura registrations.
- stoneform-preview.ogg: "Stoneform." Separate preview file, never muted by the gate.

Rebuild with Tools/generate-voice-clips.ps1 (Windows, installed voice and ffmpeg).
Encoding: mono Ogg Vorbis, 44.1 kHz, quality 4, loudness target -18 LUFS / -2 dBTP.
